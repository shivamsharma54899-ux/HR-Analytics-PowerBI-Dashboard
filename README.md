# HR Analytics Dashboard — Employee Attrition Analysis

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard built using Microsoft Power BI** to analyze employee attrition and workforce patterns.

The dashboard provides an overview of employee attrition across multiple dimensions, including **department, gender, education, job role, age, salary and job satisfaction**.

The objective of the project is to transform HR data into meaningful visual insights that can support workforce analysis and employee retention decisions.

---

## 🎯 Project Objectives

* Analyze overall employee attrition.
* Calculate and monitor the employee attrition rate.
* Identify job roles with higher attrition.
* Analyze attrition across different salary ranges.
* Examine attrition across age groups.
* Analyze the relationship between job satisfaction and attrition.
* Compare attrition across departments and gender.
* Present HR metrics through an interactive Power BI dashboard.

## 🔎 Key Insights

Based on the dashboard analysis:

* The overall employee attrition rate is **16.1%**.
* The largest number of attrition cases is observed within the **Up to 5k salary group**.
* **Laboratory Technicians** show the highest attrition among the displayed job roles.
* The **26–35 age group** represents the largest attrition group in the dashboard.
* Attrition varies across different job-satisfaction levels.
* Attrition patterns differ across departments and demographic groups.

> These observations describe patterns present in the dataset and should not automatically be interpreted as causal relationships.

## 💡 Business Recommendations

Based on the observed patterns, organizations could consider:

1. Reviewing compensation and retention strategies for employees in lower salary bands.
2. Investigating job roles with comparatively high attrition.
3. Examining employee satisfaction and engagement factors.
4. Developing targeted retention strategies for higher-attrition age groups.
5. Conducting deeper analysis by combining salary, tenure, job role, department and satisfaction indicators.

## 📂 How to Use the Project

1. Download the Excel dataset from the `Dataset` folder.
2. Download the Power BI `.pbix` file from the `Dashboard` folder.
3. Open the `.pbix` file using **Microsoft Power BI Desktop**.
4. If Power BI requests a data-source location, update the source path to the downloaded Excel dataset.
5. Refresh the data if required.
6. Explore the dashboard using the available filters and visualizations.
